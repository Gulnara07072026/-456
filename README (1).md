# Реестр судебных исков — АО «Казахтелеком»

Веб-страница для учёта входящих и исходящих судебных исков и формирования квартального и годового отчёта.

- **Файл сайта:** `kazakhtelecom_iski.html` (один файл, без установки и без интернета)
- **Технологии:** HTML, CSS и JavaScript без внешних библиотек
- **Хранение данных:** в браузере (`localStorage`), на сервер ничего не отправляется

---

## 1. Запуск

1. Скачайте `kazakhtelecom_iski.html` на компьютер.
2. Откройте его двойным кликом в **обычном** (не приватном) окне Chrome, Edge или Firefox.
3. (Необязательно) Положите рядом файл `logo.png` с логотипом Казахтелеком, либо загрузите логотип кнопкой **«Логотип…»** на странице.

> Не открывайте файл во встроенном просмотре чата или почты и не используйте приватное окно: браузер может заблокировать сохранение, и иски пропадут после обновления страницы. В этом случае вверху появится жёлтое предупреждение.

---

## 2. Что умеет сайт

| Возможность | Описание |
|---|---|
| Реестр исков | Таблица всех дел с поиском и фильтрами |
| Цветовая маркировка | **Исходящие — красным**, **входящие — зелёным** |
| Отметка «ПРОИГРАН» | Ставится автоматически по результату рассмотрения |
| Карточка иска | Клик по строке открывает все данные, есть кнопка «Копировать данные» |
| Отчёт | За квартал или за год: итоги, исходящие, входящие |
| Печать / PDF | Кнопка «Печать / PDF» на вкладке отчёта (с логотипом и строками для подписей) |
| Выгрузка в Excel | Реестр и отчёт сохраняются в CSV |
| Резервная копия | Сохранение и загрузка всех данных файлом `.json` |

## 3. Данные по иску

Обязательные поля отмечены \*.

| Поле | Пояснение |
|---|---|
| Вид \* | Исходящий (иск подан Казахтелекомом) или входящий (иск предъявлен Казахтелекому) |
| Дата подачи / поступления \* | По ней иск попадает в квартал и год отчёта |
| № дела | Номер судебного дела |
| Истец \* | ФИО или наименование |
| Ответчик \* | ФИО или наименование |
| Предмет иска \* | Суть требований |
| Сумма исковых требований, ₸ \* | Число |
| Суд | Название суда |
| Результат рассмотрения \* | Выбор из списка (см. ниже) |
| Дата решения | Необязательно |
| Присуждено / взыскано, ₸ | Необязательно, попадает в итоги отчёта |
| Примечание | Свободный текст |

Варианты результата: *На рассмотрении*, *Иск удовлетворён полностью*, *Иск удовлетворён частично*, *В иске отказано*, *Мировое соглашение*, *Прекращено / оставлено без рассмотрения*.

---

## 4. Правило отметки «Проигран / Выигран»

Результат оценивается с точки зрения Казахтелекома.

| Вид иска | Иск удовлетворён полностью | Иск удовлетворён частично | В иске отказано |
|---|---|---|---|
| **Исходящий** (КТ — истец) | ✔ выигран | Проигран частично | ⚠ **ПРОИГРАН** |
| **Входящий** (КТ — ответчик) | ⚠ **ПРОИГРАН** | Проигран частично | ✔ выигран |

«На рассмотрении», «Мировое соглашение» и «Прекращено» отметки не получают, но учитываются в отчёте отдельными строками.

## 5. Как работать

### Добавить иск
Кнопка **«+ Добавить иск»** → заполнить форму → **«Сохранить»**.

### Найти иск
На вкладке **«Реестр исков»**:
- строка поиска ищет по ФИО, предмету, № дела, суду, результату и примечанию (можно несколько слов);
- фильтры: вид, год, квартал, результат, «только проигранные»;
- клик по строке открывает карточку, **«Копировать данные»** копирует всю информацию в буфер обмена.

### Изменить или удалить иск
Кнопка **«Изм.»** в строке или **«Редактировать»** в карточке. Удаление доступно внутри формы редактирования (с подтверждением).

### Получить отчёт
Вкладка **«Отчёт (квартал / год)»** → выбрать период и год. Отчёт состоит из трёх блоков:
1. **Итого по всем искам**
2. **Исходящие иски** (красный блок)
3. **Входящие иски** (зелёный блок)

В каждом блоке: количество исков, сумма требований, выиграно, проиграно, проиграно частично, мировые и прекращённые, на рассмотрении, присуждено и взыскано, затем таблица дел. Период определяется по дате подачи или поступления иска.

Кнопки: **«Печать / PDF»** (в окне печати выберите «Сохранить как PDF») и **«Выгрузить отчёт в Excel (CSV)»**.

## 6. Резервные копии и перенос данных

Данные лежат в браузере конкретного компьютера. Они **не переносятся** на другой компьютер сами и **удаляются** при очистке данных браузера.

- **Сохранить копию данных** — скачивает файл `iski_kopiya_ГГГГ-ММ-ДД.json`. Делайте это регулярно, например раз в неделю и перед обновлением сайта.
- **Загрузить копию** — заменяет текущий реестр данными из файла (перед заменой будет запрос подтверждения).

Для переноса на другой компьютер: сохраните копию на старом и загрузите на новом.

---

## 7. Ограничения

- Один пользователь на один браузер: одновременная работа нескольких человек с общим реестром не поддерживается.
- Нет входа по паролю: любой, у кого есть доступ к компьютеру и браузеру, видит данные.
- Нет прикрепления файлов (исковых заявлений, решений судов).
- Объём хранилища браузера ограничен (около 5 МБ). Для тысяч дел и для логотипа большого размера используйте небольшие файлы.

Если нужна совместная работа, учётные записи и общая база данных, потребуется серверная версия сайта (веб-приложение с базой данных).

## 8. Структура файла (для разработчика)

Всё находится в `kazakhtelecom_iski.html`:

- `<style>` — оформление: цвета `--out` (красный) и `--in` (зелёный), стили печати `@media print`
- разметка — шапка, вкладки «Реестр» и «Отчёт», окна карточки и формы
- `<script>`:
  - `RESULTS`, `DIR_T` — справочники результатов и видов иска;
  - `lget` / `lset` — чтение и запись в `localStorage` (ключи `kt_claims_v1` для исков и `kt_logo` для логотипа);
  - `outcome(c)` — правило «выиграно / проиграно» (раздел 4);
  - `filtered()`, `renderReg()` — реестр, поиск и фильтры;
  - `stats()`, `renderReport()` — отчёт;
  - `csv()`, `dl()` — выгрузка и резервные копии.

Чтобы изменить правило отметки «проигран», правьте функцию `outcome()`. Чтобы добавить вариант результата, дополните массив `RESULTS` и при необходимости `outcome()`.
